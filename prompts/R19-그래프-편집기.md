# R19 — 그래프 편집기

키 사이의 가속·감속을 **그래프로 보며** 고치는 창을 만든다. 애프터 이펙트의 "그래프 편집기"와 같다.
지금은 키마다 이징 이름을 고르거나, 구간 하나씩 작은 베지어 편집기(`controls/bezier-editor.js`)로 고친다. R18까지 끝났다고 가정한다.

## 시작 전에

1. 읽을 파일:
   - `src/core/anim/easing.js`, `prop.js`, `position.js`(R18)
   - `src/ui/controls/bezier-editor.js`, `ease-preview.js`, `src/ui/timeline/index.js`, `track-canvas.js`(620줄 근처 커스텀 베지어 편집), `rows.js`
   - `src/core/doc/commands.js`(setKey·setKeysEase·moveKeys), `src/ui/keys.js`, `scripts/gen-easing-ref.mjs`
2. 지금 키 모델을 확인해 보고에 적는다. 구간 [키 i → 키 i+1]의 모양은 앞 키의 `ease`(+`bezier` [x1,y1,x2,y2])로 정해진다.
   그래프에서 손잡이는 이렇게 대응한다.
   - 키 i의 나가는 손잡이 = (f_i + x1·Δf, v_i + y1·Δv)
   - 키 i+1의 들어오는 손잡이 = (f_i + x2·Δf, v_i + y2·Δv)
   - Δf = f_{i+1} − f_i, Δv = v_{i+1} − v_i

## 항목

### R19-1. 그래프 창 (`src/ui/timeline/graph-canvas.js` 새 파일)

- 타임라인 머리에 [그래프] 버튼을 둔다(단축키 Shift+F3). 누르면 트랙 캔버스 자리가 그래프로 바뀐다. 다시 누르면 트랙으로 돌아온다.
  같은 시간자·재생선·확대 배율을 쓴다. R24에서 이 자리에 정식으로 통합한다.
- 보여줄 속성: 타임라인에서 고른 속성 줄. 없으면 선택한 레이어의 키 있는 속성 전부를 보여준다.
  변형·효과 수치(R16·R17) 모두 해당된다. 좌표형은 x·y 두 줄, 색·선택형은 그래프에서 뺀다(목록에 회색 표시).
- 보기 2가지:
  - **값 그래프**: 세로축 = 실제 값. 속성마다 색이 다르다. [세로 맞춤] 버튼으로 보이는 값 범위에 맞춘다.
  - **속도 그래프**: 세로축 = 프레임당 변화량. 위치처럼 곡선 경로(R18)인 경우는 경로 위 이동 속도다.
- 그리기는 구간마다 촘촘히 표본해서 선으로 잇는다. 이징 함수 결과를 그대로 쓴다.

### R19-2. 편집

- 키 점 끌기: 가로 = 프레임(정수로 붙음), 세로 = 값. 상자로 여러 키 고르기, Shift로 추가 선택, Delete로 지우기
- 손잡이 끌기: 위 대응식을 거꾸로 풀어 앞 키의 `bezier`를 바꾼다. 그 구간의 `ease`는 `'cubicBezier'`가 된다.
  - x1·x2는 0~1로 제한한다. y는 제한하지 않는다(넘침 허용).
  - Δv = 0인 구간은 세로 손잡이가 뜻이 없다(항상 평평). 가로로만 움직이게 하고 손잡이를 흐리게 그린다.
    이 한계를 보고에 적는다. 모델을 바꿔 풀지는 이번에 하지 않는다.
- **이어진 손잡이**: 키에 `smooth: true`를 저장할 수 있다. 켜져 있으면 한쪽 손잡이를 끌 때 반대쪽 기울기를 맞춘다.
  - 실제 단위 기울기:
    - 나가는 쪽 = (y1·Δv_k)/(x1·Δf_k)
    - 들어오는 쪽 = ((1−y2)·Δv_{k−1})/((1−x2)·Δf_{k−1})
  - 길이(x 성분)는 유지하고 y만 바꾼다. Alt+끌기는 이어짐을 끊는다(`smooth: false`).
- 이름 붙은 이징을 곡선으로 바꾸기: 손잡이를 처음 끌 때 근사 베지어로 바꾼다.
  - 근사표를 `easing.js`에 `EASE_TO_BEZIER`로 둔다. easeIn·easeOut·easeInOut·Cubic·Quint·Sine·Back·css 계열이 대상이다.
  - 근사 오차(최대 차이)를 `gen-easing-ref.mjs` 방식으로 재서 보고한다.
  - 탄성(elastic)·바운스는 베지어로 못 바꾼다. 회색 곡선으로 그리고, 끌면 "곡선으로 바꾸면 모양이 달라집니다 — 바꾸기 / 취소"를 묻는다.
- 아래 줄에 고른 키의 숫자 칸을 둔다: 프레임, 값, 들어오는 영향(%) = (1−x2)×100, 나가는 영향(%) = x1×100.
- 모든 조작은 되돌리기 1건이다(begin → preview → commit).

### R19-3. 키 보간 단축 동작 (타임라인·그래프 공통)

- F9 "부드럽게": 고른 키 k의 앞 구간 (x2,y2) = (0.67, 1)로, 뒤 구간 (x1,y1) = (0.33, 0)으로 둔다. 시작·끝 키는 한쪽만 바꾼다.
  - Shift+F9: 들어오는 쪽만. Ctrl+Shift+F9: 나가는 쪽만.
- Ctrl+Alt+H: 정지 키(`'hold'`, R16) 켜기/끄기
- 타임라인 키 모양으로 구분한다: 일정(linear) = 마름모, 곡선 = 모래시계, 정지 = 네모, 이름 이징 = 원(지금 모양 유지 가능).

### R19-4. 위치 곡선 경로(R18)와의 관계

- 곡선 경로 구간에서 x 키 이징은 "경로 위 진행 속도"다. 그래프에서 위치는 **속도 그래프로만** 편집하게 한다.
  값 그래프에서는 x·y를 보여주되 손잡이는 숨긴다.

## 문서 버전

- 새로 저장되는 건 키의 `smooth` 뿐이다. 없으면 false다. 버전을 올릴지 판단해서 보고한다.

## 테스트 (`tests/r19-graph.spec.js`)

- 손잡이 → bezier 변환 왕복(그래프 좌표 → bezier → 그래프 좌표) 오차 0.5px 이하.
- 이어진 손잡이: 끌고 난 뒤 키 양쪽 실제 기울기 차이 1% 이하.
- F9: 앞뒤 구간 bezier 값 확인. 시작 키는 한쪽만.
- 정지 키: 다음 키 전까지 값이 같다.
- 이름 이징 → 근사 베지어로 바뀐 직후 그래프 모양 차이가 보고한 오차 이내.
- 그래프에서 키 끌기·지우기 되돌리기 1건. 트랙 ↔ 그래프 전환 후 선택 유지.
