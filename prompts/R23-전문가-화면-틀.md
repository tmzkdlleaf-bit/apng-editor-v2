# R23 — 전문가 화면 틀

화면을 애프터 이펙트식 패널 배치로 바꾼다. 초보용 요소는 걷어낸다.
R16~R22에서 속성 패널에 임시로 넣은 조각(효과 파라미터, 시계 버튼, 가리기, 시간)을 제자리로 옮긴다.
이 묶음은 **화면 배치만** 한다. 문서 구조는 바꾸지 않는다. R22까지 끝났다고 가정한다.

## 시작 전에

1. 읽을 파일:
   - `src/ui/shell/shell.js`, `theme.js`, `status.js`, `src/app.js`, `index.html`
   - `src/styles/tokens.css`, `shell.css`, `inspector.css`, `timeline.css`
   - `src/ui/inspector/index.js` + 섹션 파일들, `section-shell.js`, `inspector/effect-params.js`(R17)
   - `src/ui/effect-gallery.js`, `motion-gallery.js`, `gallery-modal.js`, `layer-add.js`, `assets.js`, `library.js`, `templates.js`
   - `src/ui/help.js`, `demo.js`, `shortcuts.js`, `src/platform/index.js`, `src-tauri/tauri.conf.json`
2. 지금 화면 구조를 그림(글자 상자)으로 그리고, 화면 구조에 기대는 테스트 파일 목록을 적는다(`p1-shell`, `u0-screens`, `review-ui`, `u0-inspector` 등).
   - 기능을 검사하는 테스트는 **유지**한다(선택자만 바꿈).
   - 화면 모양만 검사하는 테스트는 새 구조에 맞게 고친다.
   - 무엇을 고쳤는지 목록으로 보고한다.

## 새 배치

```
┌ 메뉴 막대: 파일 · 편집 · 레이어 · 효과 · 애니메이션 · 보기 · 도움말 ───────────────┐
├ 도구 막대: 선택 · 손 · 확대 · 편집(점) · 사각형 가리기 · 타원 가리기 · 펜 · 글자 · 도형 ┤
├───────────────┬──────────────────────────────┬──────────────────────┤
│ [프로젝트|효과] │            화면              │ [효과 컨트롤|속성|정보] │
│               ├ 화면 아래 줄: 배율 · 해상도 ·  │                      │
│               │  투명 격자 · 가이드 · 안전 영역 │                      │
├───────────────┴──────────────────────────────┴──────────────────────┤
│ 타임라인 (R24에서 개편)                                                │
└─────────────────────────────────────────────────────────────────────┘
```

- **프로젝트 패널**: 가져온 에셋 목록(이미지·움직이는 이미지·PSD 조각)
  - 썸네일, 크기, 사용 수를 보여준다. 검색할 수 있다.
  - 끌어서 화면이나 타임라인에 놓으면 레이어가 된다.
  - 우클릭: 이름 바꾸기, 교체, 사용 안 하는 것 지우기
  - 지금 `assets.js`·`layer-add.js`의 가져오기 기능을 여기로 모은다.
- **효과 패널**: 검색창 + 분류(빛·날씨·파티클·오버레이·사이버·판타지·연출) 접기 목록 + 모션 클립 분류
  - 레이어(화면 또는 타임라인 줄)에 끌어 놓으면 그 레이어 효과 쌓기(R17)에 추가된다. 빈 곳에 놓으면 효과 레이어가 된다.
  - 더블클릭하면 선택 레이어에 추가한다.
  - 기존 갤러리 창(가운데 큰 창)은 없앤다. 썸네일은 목록 줄 마우스 올림 미리보기로 남긴다.
- **효과 컨트롤 패널**: 선택 레이어의 효과 쌓기와 효과 레이어 파라미터. R17의 `effect-params.js`를 옮긴다.
- **속성 패널**: 나머지 속성(배치·글자·도형·보정·가리기·시간·따라가기·움직임 번짐)
- **정보 패널**: 마우스 위치(문서 좌표), 그 위치 색(rgba), 선택 레이어 크기·위치·회전 숫자
- 모든 패널: 경계를 끌어 크기 조절, 접기, 탭 순서 바꾸기
  - 배치는 localStorage에 저장한다(읽기·쓰기 try/catch, 실패해도 기본 배치로 동작).
  - 메뉴 "보기 › 작업 공간 초기화"를 둔다.
- 화면 아래 줄 해상도: 전체 / 1/2 / 1/4 / 자동. 자동은 지금 R2-7 규칙(드래그·재생 중만 낮춤)을 따른다.
- 메뉴 막대: 지금 버튼으로 흩어진 기능을 메뉴로 모으고, 항목 옆에 단축키를 적는다.
  - 데스크톱(Tauri)에서도 같은 웹 메뉴를 쓴다(네이티브 메뉴는 이번 범위 아님).
- 화면이 좁을 때(1280px 이하): 왼쪽 패널을 접힌 상태로 시작한다.
- 색·간격·글꼴 크기는 tokens.css 변수만 쓰고, 라이트·다크 둘 다 정의한다.
  글자 크기 최소 12px. 패널 제목·숫자 칸은 작고 촘촘하게 둔다(전문가 툴 밀도).

## 걷어낼 것

- 첫 실행 자동 안내(`maybeStartOnboarding`): 자동 시작을 끈다. "도움말 › 둘러보기"에서만 연다.
- 새 프로젝트 = 템플릿 갤러리 → "새 장면 설정" 창으로 바꾼다.
  - 칸: 이름, 가로·세로, fps, 길이(프레임/초), 배경
  - 크기 프리셋 드롭다운: 코코포리아 컷인·맵시트 등 지금 `templates.js`·`export/presets.js`에 있는 크기
  - 템플릿 시작은 "파일 › 템플릿에서 새로 만들기"로 남긴다.
- 숫자 대신 말로 된 단계 표시(예: 모션의 "속도 5단계·진폭 5단계", `motion-section.js` 146줄 근처)는 숫자 칸으로 바꾼다.
  다른 곳에도 있으면 찾아서 목록으로 보고한다.
- 쉬운 말 부제·긴 설명 툴팁은 짧은 이름 + 단축키로 줄인다. UI 글자는 계속 한국어로 쓴다.

## 테스트 (`tests/r23-layout.spec.js`)

- 패널 5개가 보이고, 경계 끌기로 크기가 바뀌고, 새로고침 후 유지된다. localStorage 막힌 환경에서도 기본 배치로 뜬다.
- 효과 패널에서 효과를 이미지 레이어에 끌어 놓으면 `fx`에 추가된다. 빈 곳에 놓으면 효과 레이어가 생긴다.
- 프로젝트 패널에서 에셋을 끌어 놓으면 레이어가 생긴다.
- 정보 패널 좌표가 마우스 위치 문서 좌표와 같다(줌·이동 상태에서도).
- 첫 실행에 안내가 자동으로 뜨지 않는다.
- 기존 기능 테스트 전부 통과(선택자만 바뀐 것 허용).
- `npm run screens`로 라이트·다크 스크린샷 다시 생성. `docs/screens/` 갱신.
