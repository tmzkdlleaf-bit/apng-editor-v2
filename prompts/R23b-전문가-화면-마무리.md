# R23b — 전문가 화면 틀 마무리

R23 중 **1단계(오른쪽 도킹 패널 틀: 경계 끌기·접기·탭·localStorage 저장)** 까지 끝난 상태에서 이어 간다.
`prompts/R23-전문가-화면-틀.md`의 나머지를 이 묶음에서 끝낸다. 그 파일과 `prompts/00-전문가판-로드맵.md`를 먼저 읽는다.
CLAUDE.md 규칙과 "전문가판 규칙"을 따른다. 이 묶음은 **화면 배치만** 한다. 문서 구조(schema·migrate)는 바꾸지 않는다.

## 지금 상태 (검토에서 확인한 것)

- R16~R22(R17a·b, R21·R21b, R22a·b 포함)와 R23 1단계가 **커밋되지 않은 채** 작업 트리에 있다(변경·새 파일 87개). 마지막 커밋은 `f071138`(R16 정리).
- `npm test` 515개 중 514개 통과. 실패 1개(`f5-projects.spec.js` "메뉴 → 라이브러리 열림")는 따로 돌리면 통과한다 — 부하 때 흔들리는 테스트다.
- R23 1단계에서 된 것: `src/ui/shell/panels.js`(`createPanelDock`, `resetWorkspace`), `src/styles/panels.css`, 오른쪽 패널에 "속성" 탭 하나, `window.__resetWorkspace`(메뉴 연결 전), `tests/r23-layout.spec.js` 3개.
- 아직 없는 것: 왼쪽 패널(프로젝트·효과), 오른쪽 "효과 컨트롤"·"정보" 탭, 메뉴 막대, 위쪽 도구 막대, 화면 아래 줄, 좁은 화면 처리, 걷어낼 것 전부.
  - 효과 추가는 아직 가운데 갤러리 창(`openEffectGallery`)을 쓴다: `layer-add.js:169`, `fx-stack-section.js:32`.
  - `fx-stack-section.js`·`effect-params.js`는 아직 속성 패널 안에 있다.
  - 첫 실행 자동 안내가 아직 켜져 있다: `shell.js:110` `maybeStartOnboarding()`.
  - 모션 "속도 5단계 · 진폭 5단계"가 그대로다: `motion-section.js:146` 근처.

## 1부 — 패널 채우기

### 1-1. 왼쪽 패널 (`createPanelDock({ side: 'left', key: 'left', ... })`)

탭 두 개: **프로젝트**, **효과**. `panels.js`를 그대로 쓴다. 가운데 그리드에 `left` 영역을 더한다.

- **프로젝트 탭** (`src/ui/shell/project-panel.js` 새 파일)
  - 문서에 들어 있는 에셋 목록: 이미지·움직이는 이미지·PSD 조각. 줄마다 썸네일, 이름, 픽셀 크기, 쓰는 레이어 수.
  - 위에 검색 칸(이름으로 거르기)과 "가져오기" 버튼. `assets.js`·`layer-add.js`·`psd-import.js`의 가져오기를 이 버튼 한 곳으로 모은다. 파일을 패널 위에 끌어 놓아도 가져온다.
  - 줄을 끌어 화면에 놓으면 그 자리에 레이어가 생긴다. 타임라인 레이어 목록에 놓으면 놓은 순서 자리에 생긴다. 되돌리기 1건.
  - 우클릭 메뉴: 이름 바꾸기, 교체(같은 에셋을 쓰는 레이어 전부 바뀜), 사용 안 하는 것 지우기(R7 에셋 보존 규칙 지킴 — 쓰는 레이어가 있으면 못 지움).
- **효과 탭** (`src/ui/shell/effects-panel.js` 새 파일)
  - 검색 칸 + 분류 접기 목록: 빛·날씨·파티클·오버레이·사이버·판타지·연출, 그 아래 모션 클립 분류(등장·퇴장·반복·강조).
  - 분류 이름과 효과 목록은 `src/effects/registry.js`·모션 정의에서 읽는다. 새로 하드코딩하지 않는다.
  - 줄에 마우스를 올리면 작은 미리보기(지금 갤러리 썸네일)를 띄운다.
  - 효과 줄을:
    - 화면의 레이어나 타임라인 레이어 줄에 놓으면 → 그 레이어 효과 쌓기에 추가(`addFx`).
    - 빈 곳에 놓으면 → 효과 레이어 생성(지금 `layer-add.js`의 `_addEffect`와 같은 결과).
    - 더블클릭하면 → 선택 레이어에 `addFx`. 선택이 없으면 효과 레이어 생성.
  - 모션 클립 줄을 레이어에 놓거나 더블클릭하면 지금 모션 갤러리에서 고른 것과 같은 결과.
  - 끌어 놓을 곳 위에 있을 때 그 레이어 테두리를 강조한다.
- 가운데 갤러리 창(`openEffectGallery`, `motion-gallery.js`의 창)은 **호출하는 곳을 모두 없앤다.** "효과 추가" 버튼은 효과 탭을 펼치고 검색 칸에 초점을 주는 동작으로 바꾼다. `gallery-modal.js`는 다른 데서 안 쓰면 지운다. 지운 파일 목록을 보고한다.

### 1-2. 오른쪽 패널 탭 추가

탭 순서: **효과 컨트롤 · 속성 · 정보**. 저장된 `active`가 없으면 "속성"이 기본.

- **효과 컨트롤 탭**: `fx-stack-section.js`(효과 쌓기)와 효과 레이어 파라미터(`effect-params.js`)를 옮긴다.
  - 단일 선택일 때만 내용이 보이는 지금 규칙을 유지한다. 선택이 없거나 여러 개면 "레이어 하나를 고르세요" 한 줄.
  - 속성 탭에서 이 둘은 빠진다. 키 토글 조각(`key-toggle.js`)은 그대로 쓴다.
- **속성 탭**: 나머지(배치·글자·도형·보정·가리기·시간·따라가기·움직임 번짐·모션·카메라). 순서는 지금과 같게 둔다.
- **정보 탭** (`src/ui/shell/info-panel.js` 새 파일)
  - 마우스 위치 문서 좌표 X·Y(정수), 그 위치의 색 rgba(지금 화면에 그려진 결과 기준).
  - 선택 레이어의 위치·크기(가로·세로 px)·회전·투명도 숫자. 여러 개면 묶음 상자 기준.
  - 좌표 변환은 `view.js`의 기존 함수를 쓴다. 새로 계산하지 않는다(줌·이동·카메라가 섞여도 맞아야 함).
  - 마우스가 화면 밖이면 좌표·색 칸을 "–"로.
  - 매 마우스 이동마다 다시 그리지 말고 한 프레임에 한 번(`requestAnimationFrame`)으로 묶는다.

## 2부 — 메뉴 막대·도구 막대·화면 아래 줄

### 2-1. 메뉴 막대 (`src/ui/shell/menubar.js` 새 파일)

위쪽 막대(`topbar`)의 흩어진 버튼을 메뉴로 모은다. 웹 메뉴 하나를 데스크톱(Tauri)에서도 그대로 쓴다.

- 파일: 새 장면(Ctrl+N) · 템플릿에서 새로 만들기 · 프로젝트 목록 · 가져오기(Ctrl+I) · 내보내기(Ctrl+E) · 저장 시점 목록(R12) · 프로젝트 파일 저장/열기
- 편집: 되돌리기 · 다시하기 · 복사 · 붙여넣기 · 복제 · 삭제 · 모두 선택
- 레이어: 새 레이어(글자·도형·빈 그룹) · 그룹으로 묶기 · 그룹 풀기 · 부품으로 저장 · 앞으로/뒤로
- 효과: 효과 패널 열기 · 선택 레이어 효과 모두 끄기/켜기
- 애니메이션: 자동 키 켜기/끄기 · 그래프 편집기(R19) · 부드럽게(F9) · 루프 이음새 검사(Ctrl+Shift+L) · 모션 녹화
- 보기: 확대 · 축소 · 화면에 맞추기 · 격자 · 앞뒤 프레임 겹쳐 보기(O) · 라이트/다크 테마 · **작업 공간 초기화**(`resetWorkspaceAndReload`)
- 도움말: 단축키 안내 · 둘러보기(처음 안내) · 정보(버전)
- 메뉴 항목 옆 단축키 글자는 `shortcuts.js`의 `SHORTCUTS` 표에서 읽는다. 표에 없는 단축키를 메뉴에 새로 적지 않는다. 메뉴에만 있고 표에 없는 키가 생기면 표에 더한다.
- 키보드: Alt로 메뉴 막대에 초점, 좌우 화살표로 메뉴 이동, 위아래로 항목 이동, Enter 실행, Esc 닫기. 메뉴가 열려 있을 때 다른 단축키가 같이 동작하지 않게 한다.
- 지금 지원 안 되는 조건(예: 선택 없음에서 "그룹으로 묶기")은 항목을 흐리게 하고 누를 수 없게 한다.
- 위쪽 막대에는 메뉴 막대, 프로젝트 이름·저장 상태, 되돌리기·다시하기, 내보내기 버튼만 남긴다. 나머지 버튼(테마·도움말·캔버스 설정 등)은 메뉴로 옮긴 뒤 지운다.

### 2-2. 도구 막대

- 지금 `view.js`가 그리는 도구 버튼(`data-tool`)을 메뉴 막대 아래 한 줄 도구 막대로 옮긴다.
- 순서: 선택(V) · 손(H) · 확대(Z) · 편집(E) · 사각형 가리기 · 타원 가리기 · 펜 · 글자 · 도형.
  - `tool` 값은 지금 이름을 그대로 쓴다(`select`·`hand`·`edit`·`maskRect`·`maskEllipse`·`pen`·`motion`). 확대(`zoom`)·글자·도형 도구가 지금 없으면: 확대는 누른 곳 기준 확대(Alt+클릭 축소), 글자·도형은 누르면 그 자리에 레이어를 만드는 도구로 새로 만든다.
  - "움직이기(motion)" 도구는 도구 막대 끝에 둔다(R25에서 단축키가 바뀐다 — 이번에는 키를 바꾸지 않는다).
- 아이콘 + 짧은 이름 툴팁("선택 (V)"). 툴팁에 긴 설명은 넣지 않는다.

### 2-3. 화면 아래 줄

화면(캔버스) 바로 아래 한 줄: 배율(드롭다운 + 숫자 입력) · 미리보기 해상도 · 투명 격자 켜기 · 가이드 켜기 · 안전 영역 켜기 · 현재 프레임/전체.

- 미리보기 해상도: 전체 / 1/2 / 1/4 / 자동.
  - `editorState.previewRes`(`'full' | 'half' | 'quarter' | 'auto'`, 기본 `'auto'`). 문서에 저장하지 않고 작업 공간 저장값(localStorage)에만 둔다.
  - 자동은 지금 `stage.js`의 자동 절반 해상도 규칙(드래그·재생 중에만 낮춤)과 같다. 결과가 지금과 픽셀 단위로 같아야 한다.
  - **내보내기에는 영향이 없어야 한다.** 1/4로 두고 내보낸 결과가 전체로 두고 내보낸 결과와 바이트 단위로 같은지 테스트한다.
- 안전 영역: 코코포리아 컷인 템플릿의 안전 영역 정보가 있으면 그걸 쓰고, 없으면 가로·세로 각 90% 상자.

### 2-4. 좁은 화면·테마

- 창 폭 1280px 이하에서 처음 열면(저장된 배치가 없을 때) 왼쪽 패널을 접힌 상태로 시작한다.
- 새 색·간격·글자 크기는 `tokens.css` 변수만 쓰고 라이트·다크 둘 다 정의한다. 글자 크기 최소 12px.
- 패널 머리·숫자 칸은 촘촘하게(전문가 툴 밀도). 지금 속성 패널의 줄 높이보다 커지지 않게 한다.

## 3부 — 걷어낼 것

- **첫 실행 자동 안내**: `shell.js`의 `maybeStartOnboarding()` 호출을 지운다. "도움말 › 둘러보기"에서만 연다. 둘러보기 내용 중 R23b에서 없어진 버튼을 가리키는 단계는 새 위치로 고친다.
- **새 프로젝트 = 템플릿 갤러리 → "새 장면" 창**으로 바꾼다 (`src/ui/new-scene.js` 새 파일).
  - 칸: 이름, 가로·세로, fps, 길이(프레임 또는 초 — 둘 중 고르면 다른 쪽 자동 계산), 배경(투명/색).
  - 크기 프리셋 드롭다운: `templates.js`·`export/presets.js`에 있는 크기(코코포리아 컷인·맵시트 등)를 모아 이름과 함께. 프리셋을 고른 뒤 숫자를 고치면 "사용자 지정"으로 바뀐다.
  - 템플릿으로 시작은 "파일 › 템플릿에서 새로 만들기"에 남긴다(지금 템플릿 창 재사용).
- **말로 된 단계 표시 → 숫자 칸**: `motion-section.js`의 "속도 5단계 · 진폭 5단계"를 숫자 칸(속도 배수, 진폭 px 또는 %)으로 바꾼다.
  - 저장되는 값이 지금 단계 번호라면 문서 구조는 바꾸지 말고, 화면에서만 숫자로 보여 주고 숫자 → 가장 가까운 단계로 바꿔 저장한다. 그렇게 할 수 없으면 바꾸지 말고 이유를 보고한다(문서 구조 변경은 이 묶음 범위가 아니다).
  - 다른 곳에도 이런 표시가 있으면 `grep`으로 찾아 목록으로 보고한다(이번에 고친 것 / 남긴 것).
- **쉬운 말 부제·긴 설명 툴팁**: 짧은 이름 + 단축키로 줄인다. UI 글자는 계속 한국어. 고친 곳 수를 보고한다.
- 데모 모드(`?demo=1`, `?demo=simple`)는 테스트가 쓰므로 남긴다.

## 테스트

`tests/r23-layout.spec.js`는 그대로 두고, `tests/r23b-panels.spec.js`, `tests/r23b-menu.spec.js`를 새로 만든다.

- 패널 5개(프로젝트·효과 / 효과 컨트롤·속성·정보)가 있고, 왼쪽 패널도 경계 끌기·접기·새로고침 후 유지가 된다.
- 효과 탭에서 "빛무리"를 검색해 이미지 레이어에 끌어 놓으면 그 레이어 `fx`에 1개 추가, 되돌리기 1번에 원래대로.
- 효과를 빈 곳에 놓으면 효과 레이어가 생긴다. 더블클릭은 선택 레이어에 추가된다.
- 프로젝트 탭에서 에셋을 화면에 끌어 놓으면 이미지 레이어가 생기고, 위치가 놓은 자리 문서 좌표와 같다(±1).
- 정보 탭 좌표가 마우스 위치 문서 좌표와 같다. 줌 2배 + 이동 + 카메라 이동이 섞인 상태에서도.
- 효과 컨트롤 탭에 효과 쌓기가 보이고, 속성 탭에는 없다.
- 메뉴: 각 메뉴가 열리고, "편집 › 되돌리기"가 Ctrl+Z와 같은 결과. 메뉴의 단축키 글자가 `SHORTCUTS` 표와 일치(표에 없는 키 0개). Alt → 화살표 → Enter로 항목 실행. "보기 › 작업 공간 초기화" 후 패널이 기본 폭.
- 미리보기 해상도 1/4에서 내보낸 APNG 바이트 = 전체에서 내보낸 바이트.
- 창 폭 1200px 첫 실행: 왼쪽 패널 접힘.
- 첫 실행에 안내가 자동으로 뜨지 않는다. "도움말 › 둘러보기"로는 뜬다.
- 새 장면 창: 프리셋 고르기 → 크기 반영, 초 입력 → 프레임 자동 계산, 만들기 → 그 크기·fps·길이의 빈 문서.
- 기존 기능 테스트 전부 통과. 선택자만 바뀐 것은 허용(갤러리 창을 쓰던 테스트는 효과 탭을 쓰게 고침). 고친 테스트 파일 목록 보고.
- `npm run screens`로 라이트·다크 스크린샷 다시 만들고 `docs/screens/` 갱신.
