# R22 — 보정 레이어 범위·효과 + 그룹 시간

R21까지 끝났다고 가정한다. 두 가지를 넣는다.

- **보정 레이어**:
  - 가리기(R21)로 일부에만 적용한다.
  - 불투명도로 세기를 조절한다.
  - 효과 쌓기(R17)를 붙이면 아래 화면 전체에 효과가 걸린다(애프터 이펙트의 조정 레이어).
  - 지금은 항상 캔버스 전체에 걸린다(`layers/adjust-layer.js`).
- **그룹 시간**: 그룹에 시작 어긋남, 속도, 범위 밖 처리, 시간 다시 매기기를 준다.

## 시작 전에

1. 읽을 파일:
   - `src/core/render/layers/adjust-layer.js`, `adjust.js`, `group.js`, `instance.js`, `frame.js`, `fx-run.js`(R17), `shape-mask.js`(R21), `mask.js`
   - `src/core/anim/world.js`(R20), `evaluate.js`, `clip.js`, `seam.js`

   - `src/ui/canvas/edit-prop.js`, `inspector/layout-section.js`, `drag.js`, `path-edit.js`, `motion-record.js`(현재 프레임에 키를 넣는 모든 곳)
2. 지금 `renderGroupLayer`가 자식에게 `rctx`를 넘기는 방식과 `childRenderFn(offCtx, child, parentTr, childRctx)` 인자를 확인한다.
   `childRctx`로 다른 프레임을 넘길 수 있는지 보고한다.

## A. 보정 레이어

- 처리 순서:
  1. 아래 화면(현재 outputCtx)의 사본을 pool 캔버스로 만든다.
  2. 사본에 보정(`applyAdjust`, blur)을 적용한다.
  3. 효과 쌓기(`fx`)가 있으면 그 사본에 적용한다. `below` 소스 효과는 사본을 소스로 받는다.
  4. 가리기(R21 `masks` + 트랙 매트 `mask`)로 사본을 자른다.
  5. 결과를 불투명도(opacity × alpha)로 outputCtx 위에 덮는다.
- 가리기 좌표: 보정 레이어의 자체 좌표 = 문서 크기 사각형. 위치·회전·크기 변형도 가리기에 적용된다.
- 그룹 안 보정 레이어는 그 그룹의 아래 자식들에만 걸린다(지금 구조가 이미 그렇다). 테스트로 확인만 한다.
- 가리기·효과·불투명도가 없으면 지금 경로와 픽셀이 같아야 한다.

## B. 그룹 시간

### 데이터

```
group.time = {
  offset: 0,          // 그룹 안 0프레임이 바깥 몇 프레임에서 시작하는지
  speed: 1,           // 1 = 그대로, 0.5 = 절반 속도, 2 = 두 배
  outside: 'hold',    // 범위 밖: hold 끝값 유지 | loop 반복 | hide 안 보임
  length: null,       // 그룹 안 길이(null = 문서 frameCount)
  remap: null,        // { keys: [...] } 있으면 위 둘 대신 "바깥 f → 안쪽 f" 키로 계산
}
```

- 바깥 프레임 → 안쪽 프레임 계산은 `core/anim/time.js`의 `innerFrame(group, f)` 한 곳에서 한다.
  - remap이 있으면 `evalProp(remap, f)`
  - 없으면 `(f − offset) × speed`
  - 범위 밖이면 outside 규칙을 적용한다.
  - 안쪽 프레임은 소수일 수 있다. 움직이는 이미지는 내림, 효과·키·클립은 소수 그대로 쓴다.
  - 결정론이 유지되는지 확인한다.
- 그룹이 겹쳐 있으면 차례로 변환한다.
  `world.js`의 `worldTr(doc, id, f)`가 내부에서 조상 그룹 시간을 따라 프레임을 바꿔야 한다.
- 문서 버전 +1. `time`이 없으면 지금과 같다.

### 렌더

- `renderGroupLayer`가 자식에게 `{ ...rctx, f: innerFrame(group, f) }`를 넘긴다. hide 범위면 그룹을 그리지 않는다.
- 그룹 자신의 변형은 바깥 프레임으로 계산한다.
- 가리기 소스(renderMask)·효과 소스가 그룹 안 레이어를 가리킬 때도 그 레이어 기준 프레임으로 그린다.
- 인스턴스(복제본)가 그룹을 가리키면 인스턴스 자체에도 `time`을 줄 수 있게 한다. 같은 함수를 쓴다.

### 편집 규칙 (중요)

- `editorState.f`는 항상 바깥(최상위) 프레임이다.
- 그룹 안 레이어에 현재 프레임으로 키를 넣는 모든 곳은 `localFrame(doc, layerId, f)`로 바꿔서 넣는다. remap이면 반올림한다.
  대상: 속성 패널, 화면 끌기 + 자동 키, 경로 점, 움직임 녹화, 가리기 모양, 효과 수치.
  1단계에서 찾은 목록을 모두 고친다.
- 타임라인에서 그룹 안 레이어의 키·클립은 바깥 시간 위치로 그린다: 바깥 f = offset + 안쪽 f / speed.
  - 끌어서 옮기면 반대로 환산해 저장한다.
  - remap이 있으면 키를 흐리게 그리고 끌 수 없게 한다. "시간 다시 매기기가 켜진 그룹 안 키는 그룹을 열어 편집하세요(R26)" 안내를 띄운다.
- 기즈모·클릭 판정·경로 점은 world.js를 쓰므로 자동으로 맞아야 한다. 테스트로 확인한다.

### UI (임시 자리: 그룹 속성)

- "시간" 섹션: 시작 어긋남(프레임), 속도(%), 범위 밖 처리, 안쪽 길이
- "시간 다시 매기기" 시계 버튼: 켜면 키 2개(0 → 0, 끝 → 안쪽 길이)로 시작한다.
- 타임라인 `animatedProps`에 `시간 다시 매기기` 줄을 추가한다.

## 테스트 (`tests/r22-adjust-time.spec.js`)

- 보정 레이어 + 사각형 가리기: 가리기 안만 보정, 밖은 원본과 픽셀 동일.
- 보정 레이어 불투명도 0.5: 결과가 원본과 보정본의 중간(±1).
- 보정 레이어 + 효과 쌓기(물결): 아래 화면 전체가 일렁인다.
- 그룹 안 보정 레이어는 그룹 밖 레이어에 영향 없음.
- 그룹 시간:
  - offset 6이면 그룹 안 0프레임 모습이 바깥 6프레임에 나온다.
  - speed 2면 바깥 6에서 안쪽 12 모습.
  - loop·hold·hide 각각 확인.
- remap 키 (0→24, 24→0): 거꾸로 재생.
- 그룹 안 레이어를 바깥 f=10(offset 4)에서 값 바꾸기 → 키가 안쪽 f=6에 생긴다.
- 기즈모 위치가 렌더 위치와 같다(그룹 시간 + 따라가기 + 카메라 섞인 경우).
- `time` 없는 문서 픽셀 동일. 저장 왕복. 미리보기 = 내보내기. 이음새 검사가 그룹 시간을 반영한다.
