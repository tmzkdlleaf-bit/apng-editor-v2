# R21 — 펜으로 그리는 가리기

레이어 위에 펜·사각형·타원으로 모양을 그려서 그 안(또는 밖)만 보이게 한다. 애프터 이펙트의 "마스크"와 같다.
지금 있는 "다른 레이어 모양대로 가리기"(트랙 매트, `layer.mask`)는 그대로 두고 함께 쓸 수 있게 한다. R20까지 끝났다고 가정한다.

## 시작 전에

1. 읽을 파일:
   - `src/core/render/mask.js`, `frame.js`, `layer-content.js`(R17), `layers/image.js`(_applyMask), `layers/group.js`, `layers/effect.js`, `adjust.js`(applyBlur), `cache.js`
   - `src/core/anim/prop.js`, `world.js`(R20)
   - `src/ui/canvas/stage.js`, `gizmo.js`, `drag.js`, `path-edit.js`, `hit.js`, `editor-state.js`(tool 값), `src/ui/keys.js`
   - `src/ui/inspector/` 의 트랙 매트(가리기) 섹션 파일(`fx-sections.js` 또는 `info-sections.js` 중 해당 파일)
2. 이 묶음은 크다. STEP 0에서 아래처럼 나눌지 판단해 보고한다.
   - R21a: 데이터 + 렌더 + 사각형·타원 도구 + 속성 패널
   - R21b: 펜 도구 + 점 편집 + 모양 키프레임

## 데이터 구조

```
layer.masks = {
  order: ['msk_1', 'msk_2'],
  items: {
    msk_1: {
      name: '가리기 1',
      mode: 'add',             // add 더하기 | subtract 빼기 | intersect 겹친 곳만 | difference 서로 다른 곳만 | none 끔
      invert: false,
      path:    { value: { closed: true, pts: [{ x, y, ix, iy, ox, oy }] }, keys: [] },
      feather: { value: 0 },   // 가장자리 흐림(px)
      expand:  { value: 0 },   // 넓히기(+)/좁히기(−) (px)
      opacity: { value: 1 },
    },
  },
}
```

- 점 좌표는 **레이어 자체 좌표**다(R17의 레이어 내용 캔버스 기준, 왼쪽 위 0,0, 단위 px). 그래서 레이어를 옮기거나 돌리면 가리기도 같이 따라간다.
- 그룹 레이어는 문서 좌표다.
- `ix,iy,ox,oy`: 점 기준 상대 손잡이. 0이면 꺾인 점이다.
- `path` 키 보간: `evalProp`에 경로 종류를 추가한다. 점 개수가 같으면 모든 숫자를 각각 보간하고, 다르면 계단으로 처리한다.
- 문서 버전 +1.

## 렌더

- 위치: R17 렌더 순서의 3단계(효과 다음, 변형 전). 레이어 자체 좌표 캔버스에 적용한다.
  가리기가 있으면 효과가 없어도 레이어 자체 좌표 경로를 탄다.
- 가리기 알파 만들기(`core/render/shape-mask.js` 새 파일):
  - 첫 가리기가 add면 빈 상태에서, subtract면 가득 찬 상태에서 시작한다(애프터 이펙트와 같음).
  - 차례로 합성한다: add = source-over, subtract = destination-out, intersect = destination-in, difference = xor.
  - 각 가리기는 opacity만큼 연하게 그리고, invert면 그 모양만 뒤집은 뒤 합성한다.
  - expand: 양수면 같은 경로를 lineWidth = 2×expand로 테두리 칠해 넓히고, 음수면 destination-out 테두리로 좁힌다.
  - feather: `applyBlur`. 반경은 레이어 자체 좌표 해상도 배율(k)을 곱해서 쓴다.
- 기존 트랙 매트(`layer.mask`)와는 곱한다(둘 다 통과한 곳만 보임).
- 캐시: 가리기 결과는 (경로 계산값, feather, expand, opacity, mode, invert, 캔버스 크기, k)가 같으면 재사용한다. 키 없는 가리기는 매 프레임 다시 그리지 않아야 한다.
- 효과 레이어(scope box)·보정 레이어에도 가리기를 쓸 수 있게 한다. 보정 레이어 범위 처리는 R22에서 하고, 여기서는 데이터만 받아 둔다.

## 화면 도구

- 도구 3개를 추가한다: 사각형 가리기, 타원 가리기, 펜.
  - 단축키는 R25에서 정한다. 이번에는 화면 위 도구 버튼으로만 넣는다.
  - `editorState.tool` 값: `'maskRect'`, `'maskEllipse'`, `'pen'`
- 선택된 레이어가 하나일 때만 동작한다. 없으면 "레이어를 먼저 고르세요" 안내를 띄운다.
- 사각형·타원: 끌어서 그린다. Shift = 정사각형/정원, Alt = 가운데에서 그리기.
  타원은 점 4개 + 손잡이(0.5523 비율)로 만든다.
- 펜:
  - 클릭 = 꺾인 점, 끌기 = 부드러운 점(손잡이 당기기)
  - 첫 점 클릭 = 닫기, Enter = 열린 채로 끝내기, Esc = 취소
  - 그리는 동안 다음 선분 미리보기를 보여준다.
- 편집 도구에서:
  - 가리기 선을 보여주고 점·손잡이를 끌 수 있다.
  - 상자로 여러 점 고르기, 선분 위 Ctrl+클릭으로 점 추가, 점 Ctrl+클릭으로 삭제
  - 가리기 선 더블클릭 = 모든 점 골라 통째로 옮기기
- 모든 화면 좌표 ↔ 레이어 자체 좌표 변환은 world.js(R20) + 기준점(anchor)으로 한다.
  그룹 안·따라가기·카메라 상태에서도 맞아야 한다.
- 모양 키가 있으면 점을 고칠 때 현재 프레임에 키를 넣는다(자동 키 규칙은 R16과 같음).
- 모든 조작은 되돌리기 1건이다.

## 속성 패널 (임시 자리)

- "가리기" 섹션: 가리기 목록(이름 바꾸기, 순서 끌기, 삭제, 복제)
- 각 항목에 둘 것:
  - 방식 드롭다운(더하기·빼기·겹친 곳만·서로 다른 곳만·끔), 반전
  - 가장자리 흐림, 넓히기/좁히기, 불투명도
  - 모양·흐림·넓히기·불투명도에 시계 버튼(`key-toggle.js`)
- 기존 트랙 매트 섹션은 그대로 둔다. 이름은 "다른 레이어로 가리기"로 바꾼다.
- 타임라인 `animatedProps`에 `가리기 1 › 모양` 등을 추가한다.

## 테스트 (`tests/r21-masks.spec.js`)

- 가리기 없는 문서: 픽셀 동일.
- 사각형 add: 안쪽만 보이고 바깥 알파 0. subtract 하나만: 구멍. add + subtract: 도넛.
- invert, intersect, difference 결과 확인.
- feather 10: 경계에 반투명 띠(폭 기준 보고). expand +10 / −10: 경계가 각각 10px 바깥/안쪽.
- 레이어를 옮기고 돌리면 가리기도 같이 이동·회전.
- 모양 키 2개(점 개수 같음): 가운데 프레임 모양이 중간값이다. 점 개수가 다르면 계단.
- 트랙 매트와 같이 쓰면 둘 다 통과한 곳만 보인다.
- 펜으로 점 4개 + 닫기 → 가리기 생성. 되돌리기 1번에 사라짐. 저장 왕복. 미리보기 = 내보내기.
- 키 없는 가리기는 두 번째 프레임부터 캐시를 쓴다(엔진 stats로 확인).
