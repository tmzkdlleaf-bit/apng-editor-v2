# R27 — 풀·수풀 흔들림 4종 + 효과 정비

풀잎·수풀처럼 **뿌리는 고정되고 끝만 휘는** 움직임을 네 가지 방식으로 추가하고, 효과 견본 점검에서 나온 문제 3개를 고친다.
지금은 "좌우 흔들"·"흔들 회전"뿐이라 레이어가 통째로 움직인다(뿌리까지 같이 움직임).

CLAUDE.md 규칙과 "전문가판 규칙"을 따른다. 특히:
- 결정론(난수는 seed 난수기만), 루프(frame 0 = frame N), 렌더 경로에서 캔버스 새로 만들지 않기(풀에서 borrow/release), `ctx.filter` 금지.
- 새 기능이 꺼져 있으면 렌더 결과가 지금과 픽셀 단위로 같아야 한다. 단, 1번(안개·코스틱 버그 수정)은 일부러 모양이 바뀌는 것이므로 예외이며, 바뀐 테스트·기준 그림을 보고에 적는다.
- 문서 구조(schema·migrate)는 바꾸지 않는 것이 목표다. 바꿔야 하면 STEP 0에서 이유를 말하고 멈춘다.

묶음이 크다. STEP 0에서 a(1~3번 정비 + 4번 A + 7번 D) / b(5번 B + 6번 C)로 나누자고 제안해도 된다.

# 정비

### 1. 안개·코스틱에 바둑판 줄이 보인다

- 재현: `npm run sheets` → `docs/fx-sheets/fog.png`, `caustics.png`의 어두운 줄을 확대하면 칸마다 밝은 격자선이 보이고, 칸 경계가 계단처럼 보인다.
- 원인: `fog.js:52`, `caustics.js:41`의 `ctx.fillRect(gx * cw, gy * ch, cw + 1, ch + 1)`. 칸마다 1px씩 겹쳐 칠해서 **반투명 칸이 겹친 자리가 두 번 칠해져** 밝은 줄이 된다.
- 고칠 방향: 칸 값을 풀에서 빌린 작은 캔버스(cells×cells)에 `ImageData`로 한 번에 쓰고, `imageSmoothingEnabled = true`로 화면 크기에 늘려 그린다. 겹침도 계단도 같이 사라진다.
  - 같은 방식(`fillRect`로 칸 그리기 + 겹침)을 쓰는 다른 효과가 있는지 `src/effects/` 전체에서 찾고 같이 고친다.
- 테스트: 짙기가 고른 구간에서 칸 경계 열·행의 밝기가 바로 옆 픽셀보다 튀지 않는지(차이 ≤ 2/255). 결정론·루프 테스트는 그대로 통과.

### 2. 밝은 배경에서 거의 안 보이는 효과

- 재현: `docs/fx-sheets/`의 밝은 배경 줄(아래 줄)에서 아래 효과들이 거의 안 보인다:

  - 파라미터 이름·선택지 문구는 바꿀 수 있는 기본값으로 보고한다.
- 테스트: 밝은 배경(#eceef2) 위에서 `테두리`·`진하게`일 때 효과가 그린 픽셀과 배경의 밝기 차이 평균이 `끔`보다 확실히 크다(2배 이상). `끔`은 기존 결과와 픽셀 동일.

# 풀·수풀 흔들림 4종

네 가지는 쓰임새가 다르다. 효과 탭 설명(description)에 "언제 쓰는지"를 한 줄씩 적는다.

| | 이름(기본값) | 종류 | 쓰임새 |
|---|---|---|---|
| A | 바람 흔들림 | 움직임(반복) | 내 그림 레이어 하나에 바로 얹는 간단한 흔들림 |
| B | 바람 휘기 | 효과(소스 휘기) | 수풀 그림을 자연스럽게 휘기. 위치마다 엇박자 |
| C | 풀숲 | 효과(직접 그림) | 그림이 없어도 풀을 그려서 흔들기 |
| D | 기울기 흔들림 | 움직임(반복) + 새 채널 | 가장 가볍고 단순한 기울기 |

공통:
- 고정할 쪽(뿌리 위치): A·B는 `아래`(기본) / `위`(매달린 것: 등불·덩굴·고드름). B는 `왼쪽` / `오른쪽`(깃발)도.
- **세기**, **휘는 정도**(고정점에서 멀수록 얼마나 더 휘는지: 곡선 지수), **엇박자**(끝이 뿌리보다 늦게 따라오는 정도), **돌풍**(가끔 세게 부는 정도, 0이면 고른 흔들림).
- 속도는 "한 번 재생 동안 몇 번 흔들리는지"(정수). 돌풍도 루프 길이 안에서 정수 주기로 만들어 frame 0 = frame N.
- 난수는 seed 난수기만. seed 파라미터를 둔다.

### 4. A — 움직임 "바람 흔들림"

- `motions/loop.js`에 추가. 기존 `slices` 채널(가로 띠 밀기)을 쓴다: 띠마다 `dx = 세기 × (고정점에서의 거리)^휘는정도 × sin(위상 − 엇박자 × 거리) + 돌풍`.
- 파라미터: 세기, 휘는 정도, 엇박자, 돌풍, 띠 수(고급, 기본 48, 16~128), 고정할 쪽(아래/위), 횟수, seed.
- **지금 `channels.js`의 띠 그리기에서 고칠 점 두 가지**:
  1. 띠마다 `ctx.rect(left, y0, cw, bh)`로 잘라서, 옆으로 민 부분이 레이어 폭 밖으로 나가면 **잘린다**(풀 끝이 잘림). 바람용은 가로로 자르지 않아야 한다. 띠에 `clipX: false` 같은 표시를 두고, 표시가 없으면(글리치 등) 지금과 같게 한다.
  2. 띠 경계가 소수점 픽셀이면 잘라내기 경계가 흐려져 **띠 사이에 가는 틈·줄**이 생긴다. 바람용 띠는 경계를 렌더 배율 기준 정수 픽셀로 맞추고 1px 겹쳐 그린다(불투명 콘텐츠에서 틈 0). 반투명 테두리에서 겹침이 줄로 보이지 않는지 확인한다.
- 휜 끝이 레이어 상자 밖으로 나가므로, 미리보기·내보내기에서 잘리지 않게 여유(bleed)를 계산에 넣는다(이 모션이 있으면 세기만큼). 기존 bleed 처리 방식을 따른다.
- 테스트: 고정점 쪽 띠의 dx = 0, 반대쪽 끝 띠의 |dx| 최대. 루프 이음매. 띠 사이 틈 0(불투명 사각형 레이어에 적용 → 내부에 투명 픽셀 0). 레이어 폭 밖으로 나간 부분이 그려짐.

### 5. B — 효과 "바람 휘기"

- `wave.js`처럼 소스(아래 레이어/그룹)를 받아 휘는 효과. 물결은 화면 전체를 같은 모양으로 흔들지만, 이건 **고정점에서 멀수록 더 휘고, 가로 위치마다 엇박자**가 있어 수풀이 포기마다 따로 흔들리는 느낌을 낸다.
- 그리는 방법: 소스를 작은 조각(고정점 방향으로 2px 띠 × 가로 방향 칸)으로 나눠 조각마다 밀어서 그린다. 칸 수는 고급 파라미터(기본 24).
  - 가로 위치마다 위상차: seed 노이즈(`fbm`)로 칸마다 다른 위상·세기. **칸 사이 경계에서 밀림이 뚝 끊기지 않게** 이웃 칸과 부드럽게 이어지게 보간한다(조각 경계 틈·계단 0).
- 파라미터: 고정할 쪽(아래/위/왼쪽/오른쪽), 세기, 휘는 정도, 엇박자, 포기마다 다르게(0~1, 가로 위치 위상차), 돌풍, 횟수, seed, 칸 수(고급).
- 성능: 768×768 소스에서 프레임당 8ms 이내. 넘으면 칸 수 기본값을 낮추고 보고한다.
- 테스트: 결정론, 루프, 고정점 쪽 1px 줄은 소스와 픽셀 동일, 세기 0이면 소스와 픽셀 동일, 조각 경계 틈 0, 성능.

### 6. C — 효과 "풀숲"

- 그림 없이 풀잎을 직접 그려서 흔든다(낙엽·꽃잎 같은 방식, `날씨` 분류 — 분류는 바꿀 수 있는 기본값).
- 풀잎 하나 = 뿌리에서 끝으로 가는 곡선(2차 베지어) + 끝으로 갈수록 가늘어지는 잎 모양. 흔들림은 끝점·조절점을 옮겨서 휜다(4번 공식과 같은 바람 모델을 공용 함수로 `_fx-util.js`에 두고 A·B·C가 같이 쓴다).
- 파라미터: 개수, 높이, 높이 들쭉날쭉, 잎 폭, 바닥 위치(세로 비율), 깊이 줄 수(1~3: 뒤 줄일수록 작고 어둡고 느리게), 색 2개(뿌리 색·끝 색), 바람 세기, 엇박자, 돌풍, 횟수, seed, 밝은 배경용(2번 공용 파라미터).
- 성능: 기본값(개수 120)에서 768×768 프레임당 4ms 이내.
- 테스트: 결정론, 루프, 바람 세기 0이면 모든 프레임이 같음, 바닥 위치 아래로는 그리지 않음(뿌리가 바닥선에 붙음).

### 7. D — 새 채널 "기울기" + 움직임 "기울기 흔들림"

- 모션 계약에 채널 `skewX`(도, 기본 0)를 추가한다. **고정점(기본: 레이어 아래 가운데)을 기준으로** 가로로 비스듬히 민다(아래는 그대로, 위는 옆으로).
  - `contract.js` 머리 주석, `isLoopSeamOk`의 키 목록, `clip.js` 합산, `matrix.js`(또는 변형 계산 파일), 기즈모/히트 검사(기울어진 레이어를 눌렀을 때 맞게 잡히는지)를 같이 고친다.
  - 기울기 기준점은 모션 파라미터로 "아래/위"만. 레이어 기준점(anchor)과는 따로 계산한다(기준점을 옮긴 레이어도 뿌리가 바닥에 붙어 있게).
- 움직임 "기울기 흔들림"(`loop.js`): 파라미터 세기(도), 고정할 쪽(아래/위), 돌풍, 횟수, seed.
- 이 채널은 움직임 결과일 뿐 문서에 저장되는 값이 아니므로 schema·migrate는 바꾸지 않는다. 키프레임으로 쓰는 "기울기 속성"은 이번에 만들지 않는다(필요하면 다음 묶음 후보로 보고).
- 테스트: skewX 0이면 기존과 픽셀 동일(모든 기존 모션 테스트 통과). 고정점 줄은 안 움직임. 루프. 클릭 히트가 기울어진 모양을 따라감.

  1. 풀 그림 PNG(배경 투명) 하나 가져오기 → 레이어로 놓기 → 움직임 "바람 흔들림" → 재생: 뿌리는 그대로, 끝만 휘는지. 끝이 잘리지 않는지.
  2. 같은 그림에 움직임 "기울기 흔들림" → 비교.
  3. 그림 레이어를 숨기고 효과 "바람 휘기"의 소스로 연결 → 포기 다르게 0 / 1 비교.
  4. 새 프로젝트에 효과 "풀숲"만 → 깊이 줄 수 3, 돌풍 올려 보기.
  5. 밝은 배경에 "반짝임" → 밝은 배경용 끔/테두리/진하게 비교.
  6. "안개"를 확대해 격자 줄이 없는지.
