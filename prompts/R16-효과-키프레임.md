# R16 — 효과 수치 키프레임

효과 레이어의 수치(세기·반경·색·중심 등)를 시간에 따라 바꿀 수 있게 한다. 예: 빛무리 세기 0 → 1로 점점 밝아지기.
CLAUDE.md 규칙을 따른다. `prompts/00-전문가판-로드맵.md`를 먼저 읽고, 그 안의 "전문가판 규칙"을 CLAUDE.md에 추가하는 것으로 시작한다.

## 시작 전에

1. 읽을 파일:
   - `src/core/anim/prop.js`, `easing.js`, `evaluate.js`, `seam.js`
   - `src/core/doc/commands.js`(setProp·setKey·removeKey·moveKeys·retimeKeys·setKeysEase), `schema.js`, `part.js`, `variants.js`
   - `src/core/render/layers/effect.js`, `src/effects/registry.js`, 효과 파일 몇 개(glow·chromatic·wave), `_fx-util.js`
   - `src/core/io/migrate.js`, `project-file.js`
   - `src/ui/inspector/effect-section.js`, `layout-section.js`(현재 프레임 키 토글), `src/ui/timeline/rows.js`, `track-canvas.js`, `src/ui/loop-check.js`
2. 효과 파일 전체에서 `params`의 `type` 종류를 모아 보고에 적는다(지금 확인된 것: float, int, coord, color, select).
3. `track-canvas.js`와 `rows.js`에서 `layer.transform[key]` 처럼 변형 속성만 가정한 자리를 모두 찾아 목록으로 적는다.

## 데이터 구조

- 효과 레이어에 `paramAnim: { [파라미터키]: { keys: [...] } }`를 추가한다.
  - 정적 값은 지금처럼 `params[key]`에 둔다. `paramAnim[key]`에 키가 있으면 키 값이 이긴다.
  - 경로 문자열은 `paramAnim.<key>` → 기존 `setKey / removeKey / moveKeys / retimeKeys / setKeysEase`가 그대로 쓸 수 있게 한다.
- 키의 `v`는 파라미터 종류를 그대로 따른다: 숫자, `{x,y}`, `'#rrggbb'`, select 값(문자열).
- 문서 버전 +1. 예전 문서는 `paramAnim`이 없을 뿐이며 결과는 그대로다.

## 항목

### R16-1. 값 계산 확장 (`core/anim/prop.js`)

- `evalProp`가 키 값 종류에 따라 보간한다.
  - 숫자: 지금 그대로. 기존 결과와 비트 단위로 같아야 한다.
  - `{x,y}`: x·y 각각 같은 비율로 보간한다.
  - 색 `'#rrggbb'`: RGB 각각 보간 후 반올림해 `'#rrggbb'`로 돌려준다.
  - 그 밖(문자열·참거짓): 계단. 다음 키 전까지 앞 키 값을 유지한다.
- 이징 `'hold'`(정지 키)를 추가한다. 어떤 종류든 다음 키 전까지 앞 키 값을 유지한다. `EASE_LABELS`에 `'정지'`.
  그래프 편집기(R19)에서도 쓴다.

### R16-2. 효과 수치 계산 한 곳 (`core/anim/params.js` 새 파일)

- `evalEffectParams(layer, effectDef, f)` → 정적 `params` + `paramAnim` 키 값을 합친 객체를 돌려준다.
  - 정의의 `default`로 빈 값을 채운다. float는 min/max로 막고, int는 반올림 후 막는다.
- `render/layers/effect.js`는 `layer.params` 대신 이 함수의 결과를 효과에 넘긴다.
- `core/`는 DOM을 쓰지 않는다는 규칙을 지킨다.

### R16-3. 명령 (`core/doc/commands.js`)

- `setParamAnim { id, key, on, f }` 명령을 추가한다. 되돌리기 1건이다.
  - `on: true`: 현재 프레임 `f`의 계산값으로 키 1개를 만든다(이징 linear).
  - `on: false`: 현재 프레임의 계산값을 `params[key]`에 넣고 `paramAnim[key]`를 지운다.
- 기존 키 명령들이 `paramAnim.<key>` 경로에서도 동작하는지 테스트로 확인한다.
  기존 키 값을 바꿀 때 이징·베지어를 유지하는 R2-3 규칙도 똑같이 적용한다.

### R16-4. 속성 패널 (`inspector/effect-section.js`)

- 파라미터 줄마다 왼쪽에 **시계 버튼**(키 쓰기 켜기/끄기)과 **현재 프레임 키 마름모**, **이전/다음 키로 가기** 화살표를 단다.
- 이 묶음은 공용 조각으로 만든다: `src/ui/controls/key-toggle.js`(시계 버튼 + 마름모 + 화살표).
  `layout-section.js`의 키 마름모도 이 조각을 쓰게 바꾼다. R23~R24에서 자리를 옮길 때 그대로 쓴다.
- 값을 바꿀 때의 규칙:
  - 그 파라미터에 키가 있으면 현재 프레임에 `setKey`를 한다.
  - 키가 없고 자동 키(`editorState.autoKey`)가 켜져 있으면 `setParamAnim on` 다음에 값을 넣는다. 둘을 한 묶음으로 처리해 되돌리기 1건으로 만든다.
  - 둘 다 아니면 지금처럼 `params`를 바꾼다.
- 드래그 중(preview)에는 컨트롤을 다시 만들지 않는 기존 규칙(`_buildKey`)을 지킨다.
- 여러 효과 레이어를 같이 고른 경우: 시계 버튼은 모두 같은 상태일 때만 켜짐으로 표시하고, 섞여 있으면 "섞임"으로 표시한다.

### R16-5. 타임라인

- `rows.js`의 `keyedProps`를 일반화한 `animatedProps(layer)`를 만든다.
  변형 5종 + 효과 레이어의 `paramAnim` 키를 담고, 라벨은 효과 정의의 `label`을 쓴다.
- `track-canvas.js`에서 `layer.transform[key]`를 직접 읽는 자리를 공용 `getProp(layer, path)`로 바꾼다.
  `getProp`은 `core/anim/props.js`에 둔다.
- 효과 수치 줄의 키도 선택·끌기·늘이기·복사·붙여넣기·지우기가 변형 키와 똑같이 되어야 한다.

### R16-6. 루프·이음새

- `seam.js`·`loop-check.js`가 효과 수치 키 때문에 frame 0과 끝 프레임이 달라지는 경우를 잡는지 확인한다.
  못 잡으면 잡게 한다.
- 경고 문구: "효과 수치가 처음과 끝에서 달라 반복할 때 튑니다".

### R16-7. 복제·부품·템플릿

- `duplicateLayers`, `part.js`, `variants.js`, `templates.js`, `library-parts.js`가 `paramAnim`을 그대로 옮기는지 확인한다.

## 테스트 (`tests/r16-param-keys.spec.js`)

- 빛무리 `intensity` 키 0(f0)→1(f12): f0·f6·f12 렌더 픽셀 밝기가 차례로 커진다.
- 색 키 `#000000`→`#ffffff`: 가운데 프레임 계산값이 `#808080` 근처다(±1).
- 좌표 키 보간, select 계단, `'hold'` 정지 키.
- 키 없는 문서: 기존 스냅샷 테스트 전부 통과(픽셀 동일).
- 시계 켜기 → 값 바꾸기 → 되돌리기 1번에 원래대로. 자동 키 켠 상태에서 값 바꾸기도 되돌리기 1건.
- 프로젝트 파일 저장 → 다시 열기 왕복에서 `paramAnim` 유지. 이전 버전 파일 열기.
- 내보내기(bake) 결과와 미리보기 같은 프레임 픽셀이 같다.
