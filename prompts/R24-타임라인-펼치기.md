# R24 — 애프터 이펙트식 타임라인

타임라인을 "레이어를 펼치면 속성마다 줄이 나오는" 구조로 바꾼다.
레이어 시작·끝 막대, 작업 영역, 그래프 편집기(R19)를 정식으로 넣는다. R23까지 끝났다고 가정한다.

## 데이터

- `layer.inF = 0`, `layer.outF = null`(null = 문서 끝). 레이어가 보이는 구간이다. 범위 밖이면 렌더하지 않는다.
  - 그룹 안 레이어는 그룹 안쪽 시간 기준이다(R22).
- `doc.meta.workArea = null | { start, end }`. 미리보기 재생 범위이고, 내보내기 옵션 "작업 영역만"에 쓴다.
- `layer.solo`, `layer.shy`, `layer.label`(색 라벨 8색 중 하나)
  - solo: 단독 보기. solo가 하나라도 있으면 미리보기·내보내기 모두 solo 레이어만 그린다(애프터 이펙트와 같음).
  - shy: 타임라인에서만 숨김.
- 문서 버전 +1. 없으면 지금과 같다.

## 왼쪽 칸 (`layer-list.js`)

열 구성(왼쪽부터): 눈 · 단독 · 잠금 · 색 라벨 · 번호 · 펼침 화살표 · 이름 · 스위치(숨김·효과 켜기·움직임 번짐) · 블렌드 · 다른 레이어로 가리기 · 따라가기

- 열 너비 조절, 열 보이기/숨기기(머리 우클릭)
- 따라가기 칸 옆 "끌어서 연결" 원 아이콘: 끌어서 다른 레이어 줄에 놓으면 `setFollow`(R20)
- 펼침 단계:
  - 레이어
    - 변형(기준점·위치·크기·회전·불투명도)
    - 효과(효과마다 › 파라미터)
    - 가리기(가리기마다 › 모양·흐림·넓히기·불투명도)
    - 시간(그룹)
    - 글자(글자 레이어의 움직일 수 있는 값)
  - **키가 없어도 모든 속성 줄을 보여준다**(지금은 키 있는 것만).
- 속성 줄 하나에 들어가는 것:
  - 시계 버튼 + 이전 키/키 넣기/다음 키(`key-toggle.js`)
  - 이름
  - 현재 값 숫자 칸: 좌우로 끌어서 바꾸기, 클릭해서 입력. 좌표는 x·y 두 칸, 색은 색 칸
- 맨 위 검색칸: 이름으로 레이어·속성 거르기

## 오른쪽 칸 (트랙)

- 레이어 막대: inF~outF 구간을 막대로 그린다.
  - 양끝 끌기 = 구간 조절
  - 막대 가운데 끌기 = 레이어 시간 통째로 옮기기(키·클립·inF·outF 함께). 되돌리기 1건
- 키 모양: 일정 = 마름모, 곡선 = 모래시계, 정지 = 네모(R19와 같음)
- 작업 영역 막대: 시간자 아래에 둔다. 양끝·가운데를 끌 수 있다.
- 시간자:
  - 프레임 ↔ 초 표시 전환
  - Alt+휠 = 확대/축소, 휠 = 세로 스크롤, Shift+휠 = 가로 스크롤
- [그래프] 버튼(R19): 트랙 자리를 그래프로 바꾼다. 왼쪽 칸에서 고른 속성 줄이 그래프에 나온다.
- 많은 줄: 화면에 보이는 줄만 그린다(가상 스크롤). 레이어 100개 + 전부 펼친 상태에서 스크롤 프레임 시간을 재서 보고한다.

## 재생·내보내기

- `playback.js`: 작업 영역이 있으면 그 안에서 반복한다.
- 내보내기 창에 "작업 영역만" 체크를 둔다. 켜면 그 구간을 0부터 다시 번호 매겨 내보낸다.
  루프 이음새 검사도 그 구간 기준으로 한다.
- solo 규칙은 renderFrame에서 한다(미리보기 = 내보내기).

## 테스트 (`tests/r24-timeline.spec.js`)

- 레이어 펼치기 → 변형 5줄 + 효과 파라미터 줄이 키 없어도 보인다.
- 속성 줄 숫자 칸 끌기 → 값 바뀜, 되돌리기 1건. 시계 켜기 → 키 생김.
- inF=6: 프레임 0~5 렌더에 레이어 없음, 6부터 보임. 막대 가운데 끌기 +4 → 키도 +4.
- solo: 하나 켜면 나머지 렌더 안 됨(내보내기 결과로 확인).
- 작업 영역 6~18 재생 반복, 작업 영역만 내보내기 프레임 수 13.
- shy: 타임라인 줄에서만 빠지고 렌더는 됨.
- "끌어서 연결"로 따라가기 설정.
- 레이어 100개 문서에서 타임라인 열기·스크롤 오류 없음 + 시간 보고.
- 이전 버전 문서 열기 → 결과 동일.
