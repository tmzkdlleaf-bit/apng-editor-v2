# VFX 레퍼런스 지침 — "AI/SVG 느낌" 벗어나기

이 문서는 APNG Editor v2의 효과(`src/effects/*`)를 현직 VFX 아티스트의 방식으로 다시 다듬을 때 따르는 기준이다.
Claude Code가 효과를 새로 만들거나 고칠 때 **3장(구현 규칙)과 5장(검수 체크리스트)을 반드시 통과**시킨다.
CLAUDE.md 규칙(결정적 RNG, 0프레임 = N프레임 루프, `ctx.filter` 금지, 캔버스 풀)은 그대로 우선한다.

---

## 1. 진단 — 지금 효과가 "AI/SVG처럼" 보이는 이유

| 증상 | 왜 가짜처럼 보이나 | 현직자 방식 |
|---|---|---|
| 입자 크기·위치가 고르게 퍼짐 (`rng()` 균일 분포) | 자연물은 균일하지 않다. 균일하면 "벽지 무늬"가 된다 | 큰 것 소수, 중간 몇 개, 작은 것 다수 (거듭제곱 분포) |
| 모든 요소가 같은 속도, 같은 투명도 | 시선이 머물 곳(초점)이 없다 | 주요소/보조요소를 나눠 밝기·불투명도·움직임을 차등 |
| 완벽한 원, 직선, 균일한 선 두께 | 벡터 도형 그대로라 "SVG 아이콘" 느낌 | 물방울·C·훅 모양, 불규칙하게 겹친 원, 굵고 가는 선 섞기 |
| 단색 또는 2색 선형 그라데이션 | 디지털 기본값 냄새 | 2~4단 계단식 색 램프 + 어두운 쪽은 색조 이동(보라·파랑) |
| 처음부터 끝까지 일정한 속도(선형) | 기계적이다 | 예비동작 → 정점 → 긴 여운 (약 10 : 10 : 80) |
| 매 프레임 부드럽게 움직임 | 손그림 애니의 "끊김의 맛"이 없다 | 2프레임·3프레임마다 그림 갱신(홀드) 섞기 |
| 대칭 폭발, 방사형으로 똑같이 퍼짐 | 컴퓨터가 계산한 티가 난다 | 방향 편향, 덩어리 크기 편차, 빈 공간(쉼표) 두기 |
| 가장자리가 전부 부드럽거나 전부 딱딱함 | 질감이 없다 | 같은 형태 안에 딱딱한 면 + 부드러운 면 섞기 |
| 등장·소멸이 페이드 한 가지 | 끝맺음이 싸 보인다 | 흩어짐·쪼개짐·말려 올라감·얇아짐으로 소멸 |

## 2. 현직자 원칙 (출처 요약)

### 2-1. Riot Games — League of Legends VFX 스타일 가이드 (Jin Ho Yang 작성)
- 목표 4가지: 명확성, 시각적 소음 최소화, 테마 강화, 놀라움과 즐거움.
- **주요소(primary)**: 명도 높음, 실루엣 선명, 불투명도 높음, 형태 강함, 움직임 강렬.
- **보조요소(secondary)**: 명도 낮음, 실루엣 흐림, 크기 작음, 불투명도 낮음. 주요소를 돋보이게 하는 역할.
- 명도·채도는 0%, 100% 극단을 피한다. 높은 명도·채도는 시선을 끄는 데만 쓴다.
- 보색은 한쪽을 지배색, 다른 쪽을 보조색으로. 반반 섞지 않는다.
- 손그림 질감, 부드러운 가장자리와 딱딱한 가장자리 혼합, 움직이는 형태에 모션블러.
- 중요도에 따라 크기·강도의 단계(평상시 < 일반 동작 < 필살기)를 정한다.
- 타이밍: 길게 느껴지면 이미 너무 긴 것이다.

### 2-2. VFX Apprentice (Jason Keyser, 前 Riot) — 타이밍
- 모든 효과는 **예비(wind-up) → 정점(climax, 스파이크 포함) → 여운(fall-off)** 구조.
- 패턴은 두 종류: **충격형**(순간, 점점 커짐) / **리듬형**(흐르는, 끊기는).
- 박자감: 분당 60회보다 빠르면 공격적, 느리면 치유·평온.
- 질감·기술보다 먼저 단순한 덩어리로 타이밍부터 확정한다.
- 늘이기(stretch)·번짐(smear) 프레임을 예비동작과 함께 쓰면 짧은 동작이 살아난다.

### 2-3. 실시간 VFX 업계 통념 (realtimevfx 등)
- 예비 약 10%, 동작 약 10%, 여운 약 80%. 여운을 잘라내면 싸구려처럼 보인다.
- **3-3-3 규칙**: 크기 3종, 속도 3종, 리듬 3종을 섞는다.

### 2-4. Joseph Gilland, 『Elemental Magic』 (디즈니 이펙트 애니메이터)
- 뾰족한 형태 = 에너지·빠름, 둥근 형태 = 느림·부드러움.
- 큰·중간·작은 형태를 섞고, 간격(spacing)을 일정하게 두지 않는다.
- 디지털 입자 연기는 지나치게 대칭적이고 평행해서 어색해지기 쉽다.

### 2-5. 스타일라이즈드 불 (VFX Apprentice, Daniélle Viljoen)
- 전체 윤곽은 S자 휘어짐에서 시작, 내부는 C자·훅(갈고리) 모양으로 쌓는다.
- 몸통에서 떨어져 나간 물방울 조각이 "속도감"을 만든다.
- 색: 바닥은 흰색에 가까운 레몬색 → 주황 → 끝은 빨강·보라.

### 2-6. 일본 애니메이션 촬영(撮影)·작화
- **디퓨전**: 화면을 축소·블러한 뒤 스크린 합성 → 은은한 빛 번짐.
- **파라(パラ)**: 화면 위에 큰 그라데이션을 얹어 공기·빛 방향을 준다.
- **투과광(透過光)**: 뒤에서 비치는 강한 빛, 중심 흰색 + 가장자리 색.
- 3D 이펙트만으로는 얇아 보여서 손그림 2D 이펙트를 덧그리는 경우가 많다.
- 2프레임(2s)·3프레임(3s) 작화를 기본으로, 빠른 순간만 1프레임(1s).
- 셀 셰이딩: 2~3단 딱딱한 경계 색, 그림자는 단순히 어둡게가 아니라 색조를 옮긴다.

### 2-7. 폭발·연기
- 불규칙한 원이 겹친 덩어리. 중심은 밝고 바깥은 어둡게.
- 색 그라데이션 자체가 형태(입체)를 암시한다.

## 3. 구현 규칙 (이 코드베이스 기준)

> 아래 함수 이름은 **제안**이다. 다음 단계에서 `src/effects/_fx-style.js`(가칭)로 공통화한다.
> 모든 무작위는 `rng`(시드)만 쓴다.

### 3-1. 위계: 주요소 1 + 보조요소 1~2층
- 효과마다 레이어를 `primary / secondary / accent(선택)`로 나눈다.

| 층 | 개수 비율 | 불투명도 | 명도 | 가장자리 | 움직임 |
|---|---|---|---|---|---|
| primary | 10~20% | 0.85~1.0 | 높음 (단, 순백 100%는 핵심 한 점에만) | 딱딱함 위주 | 빠르고 큼 |
| secondary | 50~70% | 0.25~0.55 | 중간~낮음 | 부드러움 | 느림 |
| accent | 10~30% | 0.6~0.9, 짧게 반짝 | 높음 | 아주 작음 | 가장 빠름 or 정지 |

- 그리는 순서: secondary → primary → accent. 보조층은 `blurToSmall`로 한 단계 흐리게 해도 좋다.

### 3-2. 크기·속도·리듬 3-3-3
- 크기 분포: 균일 `rng()` 금지. `sizeTier(rng)` → 큰 것 10%, 중간 30%, 작은 것 60%.
  - 크기 비율은 대략 큰 : 중간 : 작은 = 1 : 0.45 : 0.18.
  - 각 단계 안에서도 ±15% 흔들기.
- 속도도 3단계. **큰 것이 느리고 작은 것이 빠르다**(원근감과 무게감).
- 위치: 격자처럼 고르면 안 된다. 뭉침과 빈 공간을 만든다.
  - 방법 예: 2~4개 "무리 중심"을 뽑고 그 주변에 가우시안 분포로 흩뿌린다.
  - 가우시안 근사 = `(rng()+rng()+rng()-1.5)/1.5`.
- 리듬: 주기 3종(예: 루프 길이의 1, 1/2, 1/3)을 섞는다. 단, **루프 길이의 정수분의 1**이어야 0프레임 = N프레임이 유지된다.

### 3-3. 형태 원형(primitive)
- 완벽한 `arc(…, 0, 2π)` 원은 **accent(작은 반짝)에만** 허용한다.
- 대신 쓸 형태:
  - `teardropPath(x,y,len,width,angle)`: 둥근 머리 + 뾰족한 꼬리. 불·물방울·빗방울·불씨.
  - `hookPath` / `cPath`: 불·연기 내부 무늬, 바람 줄기.
  - `blobPath(rng, n=5~8)`: 반지름 ±20~35% 흔든 원 여러 개 합성. 연기·폭발·구름.
  - 굵기 변화 선(thick & thin): 시작 얇게 → 중간 굵게 → 끝 얇게. 번개·금·혈관·궤적.
- 같은 형태를 복사해 쓰지 말고, 형태마다 회전·비율·꼬리 길이를 다르게 한다.
- 대칭 금지: 좌우 길이, 갈래 수를 다르게 한다.

### 3-4. 색: 계단식 램프 + 색조 이동
- `stepRamp(t, stops)` 로 **2~4단 딱딱한 경계**의 색을 쓴다. 선형 그라데이션 대신.
  - 경계는 완전히 딱딱하게 하거나, 경계 폭 2~4px만 부드럽게 한다.
- 3단 표준 구성:
  1. 핵심(core): 흰색에 가까운 고명도. 면적 5~15%.
  2. 중간(body): 효과의 대표색, 채도 가장 높음. 면적 50~60%.
  3. 가장자리(edge): 색조를 옮긴 어두운 색, 채도 약간 낮춤. 면적 25~40%.
- 색조 이동 표:

| 효과 | 핵심 | 중간 | 가장자리 |
|---|---|---|---|
| 불 | 레몬 흰색 | 주황 | 진홍 → 보라 |
| 번개·전기 | 흰색 | 시안 | 남색 |
| 마법·홀로 | 흰색 | 자홍 | 남보라 |
| 공포·피 | 탁한 분홍 | 진홍 | 고동색(갈색 쪽) |
| 얼음·서리 | 흰색 | 하늘색 | 청록 회색 |
| 반딧불·빛 | 연노랑 | 연두 | 짙은 청록(투명하게) |

- 순수 `#fff`, `#000`, 채도 100% 원색은 핵심 한 점 외에는 쓰지 않는다.
- 보색은 지배색 70~80% + 보조색 20~30%.

### 3-5. 타이밍
- **한 번 재생 효과(once)**: 예비 10% → 동작 10% → 여운 80%.
  - 예비 구간: 살짝 수축하거나 빛이 모인다. 반대 방향으로 조금 움직여도 좋다.
  - 정점: 1~2프레임 "과하게"(크기 110~130%, 핵심 흰색 비율 증가). 번짐(smear) 프레임 허용.
  - 여운: 감속 이징(ease-out, 지수 2~3). 마지막은 페이드가 아니라 **얇아지기·쪼개지기·흩어지기**.
- **반복 효과(loop)**: 일정 속도 금지.
  - 기본 움직임에 30~50% 크기의 "강약 박자"를 얹는다.
  - 2~3번의 작은 스파이크 + 1번의 큰 스파이크.
  - 박자 수는 루프 안에 정수 개로 맞춘다.
  - 평온한 효과(반딧불, 구름)는 분당 60회 미만, 공포·전기는 60회 이상.
- **홀드(2s/3s)**: `holdFrame(f, n) = floor(f / n) * n`.
  - 손그림 느낌을 낼 효과(불, 번개, 만화풍 폭발, 금 가기)에만 쓴다.
  - 자연물(안개, 구름, 오로라)은 1s 유지.
  - `frameCount`가 n의 배수가 아니면 마지막 묶음을 짧게 끝내 루프를 깨지 않게 한다.
  - 파라미터 `holdFrames: 1|2|3` 로 노출(기본값은 효과별로 정함).
- 번개처럼 짧은 효과: 번쩍(1프레임) → 꺼짐(1~2프레임) → 다시 약하게(1프레임)처럼 **끊기는 리듬**.

### 3-6. 가장자리와 질감
- 형태 하나에 딱딱한 면과 부드러운 면이 함께 있게 한다.
  - 예: 불꽃 아래쪽은 부드럽게 번지고 위쪽 끝은 딱딱하게.
  - 구현: 딱딱한 형태를 그린 뒤, `blurToSmall`로 흐린 사본을 한쪽만 마스크해 겹친다.
- 넓은 면에는 아주 약한 노이즈(불투명도 3~6%)를 얹어 "디지털 평면"을 깬다. `drawField` 활용.
- 움직임이 빠른 요소는 진행 방향으로 늘이거나(stretch) 잔상 2~3개를 둔다(불투명도 0.4 → 0.15).

### 3-7. 후처리 (촬영 처리) — `ctx.filter` 없이
- **디퓨전**: `blurToSmall`(1/4~1/8 축소) → `screen` 또는 `lighter` 합성, 불투명도 0.2~0.45.
  - 빛 계열(빛, 반딧불, 홀로, 크리티컬)은 기본 켜기.
- **파라**: 화면 전체 큰 선형·방사 그라데이션, 불투명도 0.08~0.2.
  - 위쪽 따뜻하게·아래쪽 차갑게처럼 방향을 준다.
- **투과광**: 핵심은 흰색, 바깥 링은 대표색, 디퓨전 2겹(작은 반경 강하게 + 큰 반경 약하게).
- 후처리는 효과 하나당 최대 2개. 다 켜면 뿌옇게 된다.

## 4. 카테고리별 레시피

### 불·불씨 (`fire` 계열, `critical-burst`의 불꽃)
- 윤곽: S자 → 내부 C·훅. 위로 올라가며 갈라진다.
- 몸통에서 떨어진 물방울 조각 3~6개가 위로 날아가며 작아진다.
- 색 램프: 레몬 흰색(바닥 중심) → 주황 → 진홍·보라(끝).
- 홀드 2s 기본. 형태는 2~3장 "키 모양" 사이를 오가며 바꾼다(매 프레임 새로 만들지 않기).

### 연기·안개·구름 (`fog`, `clouds`)
- 불규칙 원 겹침(`blobPath`). 큰 덩어리 1~2개 + 중간 + 작은 꼬리.
- 위쪽 밝고 아래쪽 어두운 2단 명암(빛 방향).
- 서로 평행하게 흐르지 않게, 덩어리마다 속도와 각도 ±10~20°.

### 폭발·버스트 (`critical-burst`, `shatter`)
- 예비: 2~3프레임 수축 + 중심 빛 모임.
- 정점: 흰색 원판 1프레임(투과광) → 바로 불규칙 덩어리로 교체.
- 파편은 3단 크기, 방향은 한쪽으로 30~40% 몰리게(완전 방사형 금지).
- 여운: 연기 덩어리가 느리게 커지며 얇아짐. 전체 시간의 80%.

### 비·눈 (`rain`, `snow`, `window-rain`)
- 앞(큰·빠름·흐림) / 중간 / 뒤(작음·느림·연함) 3층. 이미 있는 depth를 이 비율로 맞춘다.
- 빗줄기는 균일 직선 대신 굵기 변화 선, 길이 편차 ±40%.
- 눈은 원 대신 약간 찌그러진 덩어리. 앞쪽 눈송이는 흐리게(frontBlur).
- 바람 방향은 한 방향으로 통일하고, 가끔(루프당 1~2회) 돌풍으로 각도 변화.

### 번개·전기 (`lightning`)
- 주 줄기 1개(굵기 변화, 핵심 흰색) + 곁가지 2~5개(얇고 흐림).
- 끊기는 리듬(3-5 참고), 홀드 2s.
- 번쩍이는 순간 화면 전체에 파라(푸른 빛) 1~2프레임.

### 빛·반짝·반딧불 (`sparkle`, `fireflies`, `holo-foil`, `aurora`)
- 반짝임은 십자형 별 + 핵심 원(이건 원 허용). 별 갈래 길이를 서로 다르게(긴 2 + 짧은 2).
- 반딧불: 깜빡임을 사인파 대신 "빠르게 켜짐 → 천천히 꺼짐" 비대칭 곡선으로.
- 디퓨전 기본 켜기.

### 공포 (`crack`, `drip`, `veins`, `madness`, `pulse-border`)
- 금·혈관: 굵기 변화 선, 갈래는 한쪽으로 몰림, 끝은 가늘게 사라짐.
- 흘러내림: 물방울 머리 + 가늘어지는 꼬리. 속도는 "멈칫 → 툭 떨어짐" 리듬.
- 맥동: 심장 박동처럼 두 번 뛰고 쉼(쿵-쿵-쉼). 분당 60회 이상.
- 색은 진홍 → 고동색으로 이동. 순수 빨강 `#f00` 금지.

### 전환 (`ink-wipe`, `paper-burn`, `card-flip`, `holo-transition`)
- 진행 곡선은 ease-in-out이 아니라 **느리게 시작 → 중간 가속 → 끝에서 튕기듯 멈춤**.
- 경계선(잉크 가장자리, 불타는 테두리)은 2~3단 색 램프 + 딱딱한 안쪽 / 부드러운 바깥쪽.
- 종이 불타기: 경계에 불씨 물방울 조각이 떨어져 나간다.

### 변형 (`drop-shadow`, `bloom`, `heat-haze`, `mosaic`, `partial-blur`)
- 그림자: 순수 검정 대신 배경 반대 색조의 짙은 색(보라·남색) + 불투명도 0.35~0.6.
- 번짐(bloom): 디퓨전 규칙과 같게. 2겹(작고 강함 + 크고 약함).
- 아지랑이: 일정 사인파 금지. 주기 3종을 섞는다.

## 5. 검수 체크리스트 (효과 하나당)

작업 후 `sheet.mjs`로 프레임 시트를 뽑아 아래를 확인한다. 하나라도 "아니오"면 다시 다듬는다.

1. [ ] 정지 화면에서 시선이 먼저 가는 곳(주요소)이 1곳인가?
2. [ ] 크기가 3단계 이상 섞여 있고, 작은 것이 가장 많은가?
3. [ ] 완벽한 원·직선이 accent 외에는 없는가?
4. [ ] 색이 3단(핵심·중간·가장자리)이고, 어두운 쪽 색조가 옮겨졌는가?
5. [ ] 순백·순흑·원색이 핵심 한 점 외에 없는가?
6. [ ] 일정 속도가 아니라 강약(스파이크)이 보이는가?
7. [ ] (once) 예비 → 정점 → 긴 여운 구조이고, 여운이 전체의 70% 이상인가?
8. [ ] 대칭이 아닌가? (좌우 뒤집어 비교해 달라야 함)
9. [ ] 가장자리에 딱딱한 곳과 부드러운 곳이 함께 있는가?
10. [ ] 소멸이 단순 페이드가 아닌가?
11. [ ] 0프레임 = N프레임, `rng`만 사용, `ctx.filter` 없음, 프레임당 8ms 이내?
12. [ ] 기존 프리셋 기본값의 인상이 크게 바뀌었다면 `docs/effects.md`에 적었는가?

## 6. 적용 순서 제안 (다음 단계, 아직 미착수)

1. 공통 도구 `_fx-style.js`: `sizeTier`, `gauss`, `stepRamp`, `holdFrame`, `teardropPath`, `hookPath`, `blobPath`, `taperStroke`, `diffusion`, `para`.
2. 대표 효과 3개로 먼저 검증: 불(또는 critical-burst) · 비 · 반짝임.
3. 카테고리별 일괄 적용: 빛 → 자연·날씨 → 공포 → 전환 → 변형.
4. 이전/이후 프레임 시트를 나란히 비교한 이미지를 남긴다.
